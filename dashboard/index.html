How sawtooth / collector merge works

Gold pattern: Greensboro PLC4 P02_Track_5ms → program Sawtooth_Merge (collector tracking + lane reservation).

Example equipment (PLC4): lanes P412 / P120 / P218 (+ buffers) → collector P414 (+ P418), carton-track encoder P414_Enc (ENC* from RUN).

Encoders: set the collector tracking encoder in section 1 (required when track is enabled). Optional per-lane encoders are on each lane row.

RUN tar.gz: yes — FortnaPlus tables SawMerge.asc, SawLane.asc, HSSawLane.asc, HSSawParm.asc (QNX saw-merge / C-side). Autogen emits Logix pack from gold L5X; Asc tables feed site parameters later.

Design here → Apply → Compile hub READY → Export L5X (Sawtooth_Merge included when READY).

Sawtooth Merge Build Not detected
Import a RUN — Sawtooth auto-populates when SawMerge/SawLane evidence exists. No Discover button required.
General · Collector
Collector tracking encoder

Required when Enable collector track is on and no collector encoder is selected yet. Role must come from RUN evidence (Jamzone / MotorIO / associations) — not the first ENC### in the list.

City-counter encoders (e.g. ENC424 / CITY COUNTER) are a different function and must not be selected as the sawtooth collector tracker.

Lanes (RUN auto)
Review conveyor · PE · drive · slice/reserve from SawLane. Unresolved fields stay visible — do not invent values.
Advanced · collector jam PEs / track / HMI timing (engineer CFG)
Collector PEs / enables

Maps to Enable_Merge2_Trk, Enable_Merge1_Reserv, Use_GapStore_Belts, jam PEs on collector (PE414_J / A–D), and EOW.

4 · Collector track PEs
PLC4 calibrates collector PE pulse locations for carton tracking (ST routines RT_CollPeTrackCal / RT_CollTrackHist). Leave 0 if you will fill later in Studio.
5 · Tracking system params (PLC4 HMI / ST_CollTrkSysCfg)

Site values that feed P###_SawMerge_HMI and collector track ST ((RT_CollTrackMain, RT_DeltaDist_*, SR_LaneCntrl). Anything not listed here can still be tuned manually in Studio after Export.

PLC4 reference · what Autogen will wire

Program Sawtooth_Merge (Main → Conv_Fast / Conv_PE / Conv_Enc + ST track/reserve). Instance prefix MRG{id}_*, HMI P{id}_SawMerge_HMI (ClctrSpeed_FPM, ClctrRunOutDist, ClctrSlugGapAdder, ClctrSrtSafteyTmrPreset, Lane[]). ST track: RT_CollTrackMain, RT_CollTrackResvMngr, RT_CollPeTrackCal, SR_LaneCntrl, RT_DeltaDist_NoGapStore / RT_IO_Map_NoGapStore when gap-store is off. Tar.gz Asc tables (SawMerge / SawLane / HSSawParm) remain C-side; Logix pack is the L5X template. Anything not captured above can be finished manually in Studio after Export.

A · Create a new Area from conveyors

    2.

    3.

    4. 
              
  4. When the blue bar shows Selected: N conveyors, click
                Create Area from Selection and name it (e.g. ModuleB_Area).
    5. 
              
  5. Area membership is engineer metadata — geometry never invents Areas.
    6.

  1. Select conveyors again (box or Ctrl-click).
    2.

    3. 
              
  3. Remove Selection from Area — send to Unassigned.
    4. 
              
  4. Or use bulk Apply Area / ES on the selection bar.
    5. 
              
  5. Toolbar Area dropdown switches which Area you are viewing/editing · New creates an empty Area.
    6. 
              
  6. When topology + Areas look right → Apply to Autogen → Compile hub READY → Build PLC.
