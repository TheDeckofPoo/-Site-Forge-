Glossary of Terms
AC – Automation Controller
FPC – FortnaPlus Control
PE – Photo Eye.  A device used to detect the presence of a container using a beam of light.
SSV – Solenoid Valve.  An output used to activate an actuator.
CPN – A generic term for an AC.  We once called “Automation Controllers” “Control Panels”, hence the “CP”, and the “N” is as in:  “The n-th one”.  Yeah, so now you know 😊

Merge Control
When two or more sections of conveyor merge into one, precise timing is required to provide a smooth convergence and to maintain the desired spacing between containers.  FortnaPlus supports several merge variants to match hardware configurations for various application requirements.
Simple Merge
The Simple Merge module is used to control a single merge lane entering a main line.  Both the main line and the merge lane run at a fixed speed.  Each requires a presence PE.  The main line must have sufficient space between containers to allow containers to flow from the merge lane.  Containers are allowed to flow from the merge lane when:
The main line is running
The main line presence signal is OFF (Nothing is present on the main line)
The merge lane presence signal is ON (A container is present on the merge lane)
The FullClear timer for the main line presence signal has timed out, indicating space is available to accept a container from the merge lane.

SimpleMerge Table
For Simple Merge merges, all configuration is done using a single table:  SimpleMerge (Configuration Menu | Merge Utilities | Simple Merge).
SimpleMerge Table
Field
Type
Description
Name
String
Define a unique name for the merge.
MainLineRun
PopUp
Choose the run signal for the main line.
ClearTimer
PopUp
Choose the retentive Full-Clear timer that defines the interval to hold the feed lane once the MainLinePresence sensor goes off.  The timer will be created automatically at startup if the Name and LanePresence fields are populated.
MainLinePresence
PopUp
Choose the signal that indicates a container is present on the main line.  When this signal is ON, and until ClearTimer has expired, the merge lane will hold.  This is the PE across the main line.
LanePresence
PopUp
Choose the signal that indicates the merge lane has a container present.  This is the PE across the merge lane.
LaneRun
PopUp
Choose the signal that will be disabled when the main line has a container present.  This is the motor for the merge lane.
DontFireLaneRun
Y/N
N = The LaneRun output will be fired as well as enabled when started and unfired and disabled when stopped.
Y = The LaneRun output will be enabled / disabled only.  Use this when the motor will be controlled by motor chains as a GoTo.
Machine
PopUp
Choose the AC that will control this entry.
Error
Int
Interpret the code number show in this field as follows:
0 – No error detected1 – Not controlled by this Machine2 – ClearTimer is not defined3 – LaneRun is not defined4 – MainLinePresence is not defined5 – LanePresence is not defined
pRun
Int
Set by the software.  0 = LaneRun is being set to OFF.  1 = LaneRun is being set to ON.  Only meaningful if Error = 0
NoGap
Y/N
Determines if containers on the merge lane are allowed to advance to the LanePresence PE or not when the main line is running and has containers present.
N = Containers may proceed to the LanePresence PE even if the MainLinePresence PE is blocked or ClearTimer has not timed out.  The merge lane will stop when a container arrives at the LanePresence PE and wait for the main line to clear.  There must be a gap between containers on the merge lane for this to work effectively.
Y = The merge lane may run only when the main line is clear.  This is useful if there is no gap between the containers on the merge lane.
LaneGoto
Y/N
N = The merge lane will stop when the main line stops.
Y = The LanePresence PE will act as a GoTo eye, even if the main line is stopped.  This allows the containers on the merge lane to advance to the LanePresence PE regardless of the state of the main line.

Multiple Input Lane Merge (New Merge)
The New Merge module can be used with a variety of hardware configurations, such as Two-to-One, Three-to-One, or Three-to-Two layouts.  Configuration tables are used to define the input points, routes, and output signals required.  Each possible route from an input lane to an output lane is explicitly defined.  “Not Busy” routes must be defined.
MergeBoss Table
Each New Merge needs a MergeBoss entry (Configuration Menu | Merge Utilities | New Merges | Merge Boss).

Valid

Set by the software – only at startup.  N indicates input lane configuration errors have been detected.  The pStatus field indicates the specific error detected.  Y indicates no error has been detected.
SwitchDelayTimer
PopUp
Optional.  Choose a timer and set SwitchDelayTimerPreset to a non-zero value to limit the rate at which the merge can switch to another input-to-output configuration.  This is useful for merge hardware with a large “cost” associated with changing state, such as large plow arms.  The merge will hold in the “Waiting Switch” state until the timer expires.
SwitchDelayTimerPreset
Float
Preset value for use with SwitchDelayTimer.  Enter a time value, in seconds.
IsSwitchDelay
Int
Set by the software.  Tracks the state of the SwitchDelayTimer.
pStatus
String
Used by the software to show the state of the merge logic.
