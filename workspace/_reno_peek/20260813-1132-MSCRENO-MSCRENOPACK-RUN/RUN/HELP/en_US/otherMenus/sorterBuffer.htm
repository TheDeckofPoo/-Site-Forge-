Sorter Buffer Menu

This menu holds the entire length of the shifter represented as ticks and what is in the index at each tick location. A-1 is shifted as the default.

Fields:

  • Buffer Position - the tick address, starts at one and goes up to the last tick number on that sorter then begins at one again for the next sorter

  • Index - represents the product traveling on the sorter. The number indexes the SorterData table.

  • Sorter - the name of the shifter, a pop up into the Sorters table
