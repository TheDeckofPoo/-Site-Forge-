XferCheckSet Menu

The XferCheckSet Menu contains up to 5 XferCfg records:

Name - a description for this set that must be idle for a transfer to occur

Xfer1 - brings up the XferCfg menu from which to select a partial product path

Xfer2 - brings up the XferCfg menu from which to select an additional partial product path

Xfer3 - brings up the XferCfg menu from which to select an additional partial product path

Xfer4 - brings up the XferCfg menu from which to select an additional partial product path

Xfer5 - brings up the XferCfg menu from which to select an additional partial product path
