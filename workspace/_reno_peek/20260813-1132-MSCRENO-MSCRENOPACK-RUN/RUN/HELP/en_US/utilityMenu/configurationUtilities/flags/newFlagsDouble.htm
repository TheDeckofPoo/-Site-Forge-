New Flags Double

This menu allows the setting of flag variables of the number type double (having a decimal value ex. 4.5). This menu is seldom used by people other than Fortna employees.

The following menu columns are included:

  • Flag_Name - the unique indetifier name associated with this flag.

  • Flag_Value - the numerical value to be assigned to this flag
