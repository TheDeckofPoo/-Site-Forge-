Edit Layers

In this menu you will notice that the first line, line 0, is default. This line must remain a default for the main screen to work. The first column is the layer set name column ,the second column is the default view , the third column is the view column for record 1, the fourth column is the view column for record 2, and so on. So if all views are to be seen in the main view (default view) then all of the columns for line 0, will have a "Y" for yes in them. Line 1 will be for the view 1.

Click the pull-down symbol with the left mouse button to display the Layer Set Menu from which to make your selection. All parts that have a 1 in their layer box in the parts database will now show up in view 1. You will now have to activate the view. Since you want the selected view to show up on the main screen, put a Y in the default column for record 1 put a Y in the very next column which is the view column for record 1. You will repeat this procedure until all views are entered. If you would like more that one conveyor series in the same view, put a Y in the appropriate column to turn those parts on.
