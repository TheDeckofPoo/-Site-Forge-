Conveyor screen

Click on conveyor system items with the left mouse button to open the Part Database for that item.
Click on conveyor system items with the right mouse button to open the Part Editor.
Part Editor lets you to change part positions, sizes, angles and other graphics parameters.

View Window 

Click on the View Window icon to select a different view of the conveyor.

To add a new view:
Set the desired map, x,y positions and zoom level of the conveyor scroll area, enter a view name and press the button.
To modify an existing view:
Select the view. Set the desired x,y positions and zoom level of the conveyor scroll area, press the button.
Press Esc to close the View window.
