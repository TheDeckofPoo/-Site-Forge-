System Utilities

Under System Utilities are other menu options that cover the entire system.
  • Set World Views

  • Edit Layers

  • Edit Layer Set

The above three deal with selecting user views and establishing layers of parts and I/O devices for viewing.

  • Edit Conveyor Colorsets - for menu display.

  • Device I/O - shows states of all devices.

  • System Errors - accesses current and history of system errors.

  • System Timers - allows addition and editing of timers used in configuration.
