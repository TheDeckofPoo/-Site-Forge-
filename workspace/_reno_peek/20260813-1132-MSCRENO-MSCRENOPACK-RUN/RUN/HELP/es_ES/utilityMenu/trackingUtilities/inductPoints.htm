Induct Points

A record is needed for each inpoint. Inpoints are configured here and, once saved and reloaded, will configure correctly in the Sorter Configurations menu. Record zero must be left N/A.

The following columns are included in this menu:

Inpoint Name - if name is left blank.

Sorter - an identifiable name, if left blank, fills in automatically.

Induct Number - Induct number for the sorter, starting with 0.

Induct Location - typically we induct at address of 30.

Induct I/O Name - pull-down into Conveyor file.

Trailing Edge Pad - the number of ticks padding the trailing edge.

Minimum Gap - distance in ticks between product.

Longest Package - length in ticks of the longest package.

Data - automatically set to the last Data table record number used.

Gap Aborts - the number of gap aborts.

Cons Gap Aborts - the number of consecutive gap aborts.

Cons Gap Abort Flag - automatically set to Y if we are currently having gap aborts.

Maximum Gap Aborts - maximum number of gap aborts allowed before displaying an error.

Gap Abort Error - pull-down into the Errors Menu.

Reset Cons Gap Aborts - when manually set to a Y, will reset gap abort totals.

Inducting - a boolean field used in combiners. A Y causes bad gap checking.

Mergetype - used with inducting to configure combiners.
