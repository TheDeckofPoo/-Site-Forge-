Connection Types

The Connection Types screen lists the types of connections to systems or devices supported by FortnaPlus© for data exchange. The Connection Types screen also shows the functions used to initialize the connection, maintain the connection, send and receive messages for the connection.

The following are connection types currently supported by FortnaPlus©:

  • N/A - used in other tables as a filler. Its init, maintain, send, and receive functions should all be set to page 0. This must always be the first entry in the connect table.
  • Connect_TCP - used to connect systems using TCP/IP sockets
  • Connect_Serial - used to connect systems using serial communications or devices that communicate serially such as scanners and scales.
  • Connect_Disk - used to connect systems that send messages via the hard disk.
  • Connect_Modem - used to connect systems that send messages through the modem

The normal values for these connection types are:

Protocol Init Function Maintain Function Send Function Receive Function
CONNECT_QNX qnx_init qnx_maintain qnx_send qnx_receive
CONNECT_TCP tcp_init tcp_maintain tcp_send tcp_receive
CONNECT_SERIAL ser_init N/A ser_send ser_receive
CONNECT_DISK disk_init N/A disk_send disk_receive
CONNECT_MODEM modem_init modem_maintain modem_send modem_receive
