Batches

The Batches menu is used to assign system procedures to nodes on the network and to assign execution timing. We will refer to the following fields when configuring batch processing:

Fields:

File Name - a meaningful name of 25 characters for the procedure

Description - a meaningful description of 25 characters

Current Num - an integer. NOT USED

How Often - the number of increments that pass before calling on the procedure
example: do every 2 minutes

Increment - brings up the Increments table where various increments of time are displayed.
Not used when Type is Count.

Current Stat - handled internally, not used when Type is Absolute

Was Stat - when applicable, displays the status of the increment used from the Today Menu

Type - brings up the Type of Interval menu which displays four options:

None -
Elapsed - calls the procedure after the increment of time has elapsed
Absolute- calls the procedure at a specific increment
Count - calls the procedure once every time through the critical loop of the program

Process - brings up the Process Type menu which displays the four system processes

GUI - priority of 10, polled for activity approximately every 1/4 sec or every 250ms
CTRL - priority of 12, polled for activity approximately every 1/10 sec or every 100ms
SORT - priority of 13, polled for activity approximately every 1/20 sec or every 50ms
SERV - priority of 11

Internal Proc - brings up the list of procedures initialized in the project.c file. Choose from this list with the GUI or SERV processes.

Internal Proc Ctrl - brings up the procedures controlled by the ctrl process through the cproject.c file. Choose from this list with the CTRL or SORT processes.

Machine - brings up the Machine menu listing all the machines on the FortnaPlus© network
Chose the machine to execute the procedure.

All Machines - a boolean field accepting Y or N indicating if all the machines should do the procedure

DoFile - a boolean indicator that determines whether or not a shell is opened to run a batch file

EXAMPLE:   CREATE A BATCH TO SAVE DATA EVERY EVENING AT 3AM

1. Select Administration Utilities from the Main menu.

2. Select Batches

3. Begin with record 0 or the first empty record.

4. Type "fortna menus" in File Name field.

5. Type "timed saving of data" in the Description field.

6. Type 3 in the How Often field.

7. Click the pull-down symbol in the Increment field, select Hour

8. Click the pull-down symbol in the Type field, select Absolute

9. Click the pull-down symbol in the Process field, select GUI

10. Click the pull-down symbol Internal Proc field, select Save Data

Select one of the machines to handle the processing in the Machine field or type Y in All Machines.
