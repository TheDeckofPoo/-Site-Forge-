Lane Table

The Briggs & Stratton name for the lanes 1 through 15 should be displayed in the name column. Please type in the names in the divert order beginning with the first divert after the scanner.

The Enable status is displayed in the second column. To disable a lane simply select disable in the pulldown for this column.

Remember to Save changes!
