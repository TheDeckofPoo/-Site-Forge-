Start / Stop Menu

This menu will allow you to start and stop the entire system or any zones in the system. Initially the system must be started with the push button on the panel. This is because there are some hard-wired relays in the control panel that must be energized before the system can be run. This is also true after an Emergency stop has been activated.

START ALL

The Start All selection allows the operator to start all zones at once.

STOP ALL

The Stop All selection allows the operator to stop all zones at once.

OTHER ZONE NAMES

Any remaining zone names are zone selections that the operator can start or stop. The first word in these remaining selections will be either START, STOP, or (NOT ENABLED). This references the action that will take place if you press the "ENTER" key while the selection is highlighted. Actions that will start zones are displayed in green and actions that will stop zones are displayed in red.

Select the zone you want to stop or start. The zones that are running will say "Stop zone name" so that when you press Enter on that zone it will stop. Likewise it will say "Start zone name" when that conveyor is ready to be started.

The line will display     Not Enabled zone name    when the relay in the control panel is not energized. The system must then be started from the control panel.  If the selection indicates (NOT ENABLED), the zone is not available for starting.  This usually indicates that an E-STOP has been activated or the panel has been turned off.
