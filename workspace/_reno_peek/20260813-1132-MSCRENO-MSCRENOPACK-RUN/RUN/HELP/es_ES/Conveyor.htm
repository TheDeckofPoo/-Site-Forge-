Conveyor Help Menu

 

Select the item to modify in the parts database. To select the part use

<Page-Up> and <Page-Down> keys or the PGUP and PGDN buttons.

You can also search for the part. Use the arrow keys to move the cursor to the

I/O Name. Press <Enter>. Enter the part ID and press <Enter> again.

 

 

The following keystrokes work on the conveyor diagram

F2

Edit any field.

Go to the field. Change the field and press Enter.

SHIFT-F5

Toggles between the abbreviated and full part description.

SHIFT-F6

Grows the selected part to the mouse click.

SHIFT-F7

Displays the part logic.

CTRL-F2

Lets you select multiple parts to edit by dragging the mouse with the left button pushed.

Check help after you are in there for more help.

CTRL-F3

Prints a parts list to the lst file on disk.

CTRL-F4

Duplicates a part.

CTRL-F6

Moves the part where the mouse clicks.

CTRL-F7

Lets you enter a maintenance report for the part.

ALT-F1

Lets you move a conveyor part with cursor keys.

ALT-F4

Deletes a part.
