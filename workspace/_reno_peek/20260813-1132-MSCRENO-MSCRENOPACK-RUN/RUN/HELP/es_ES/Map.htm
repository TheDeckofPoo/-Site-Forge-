Maps

Use maps to see a detailed area of the conveyor.

A Map is a sub-area of the conveyor screen and is characterized by the coordinates of its upper left and lower right corners.

There are two ways to create a map:

  1. Go to the PhMap menu and enter the map data by hand.
  2. Click and drag with the left mouse button to highlight the desired map area, and the new map definition will be added to the PhMap menu automatically.

To create a View using the map:

  • Activate the map using the "Map" procedure. The "Map" procedure shows the maps list on the screen.
  • Select the desired map using the arrow keys, or the numbers 0...9, which are hotkeys for maps #0...9.
  • Set the desired zoom level using the Zoom In button
  • Set the desired position of the conveyor scrollarea
  • Open the View window, type the new view name in the text field and press the   button.

Use the "Map Edit" procedure to open the Map Editor and edit the current active map.
