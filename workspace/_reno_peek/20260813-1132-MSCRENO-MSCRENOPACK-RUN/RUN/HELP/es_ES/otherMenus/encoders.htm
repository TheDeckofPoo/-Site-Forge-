Encoders

Optical Encoders are devices that interpret rotary motion on a shaft into electrical impulses, or signals. Encoders are used allow the control program to monitor how many times a shaft turned. When this informataion is used in conjunction with a timer, distance and speed of the conveyor can be calculated. Encoders are also used with photoeyes to track the movement of individual cartons or with scanners to plan precise merges of individual product cartons.

The following fields are included in this menu:

  • Encoder Name - a unique string identifier used to differentiate an encoder from other parts

  • Encoder I/O - the actual I/O name of the encoder. ex. ENCxxx

  • Encoder Timer - each encoder gets a timer to help calculate distance and speed as described above

  • Ticks per Foot - the number of impulses that the encoder sends per one foot of conveyor travelled. Set by manufacturer.

  • Encoder Ticks - the number of encoder ticks passed

  • Calculated FPM - a mathematical function based on the encoder's number of ticks passed, the number of ticks per foot, and the time recorded by the timer.

  • Target FPM - the ideal speed that the system is trying to achieve
