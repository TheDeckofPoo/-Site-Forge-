Sorter Data Menu

This menu holds a record for each entry being shifted. The records are used sequentially, and when the end of those records available to the particular shifter has been reached, it will continue at the beginning.

Fields:

  • Sorter - shifter name, a pop up into the Sorter table

  • Data - the record number in the sequence of records used by that shifter

  • Lane - automatically generated, displays the lane this product is to divert at

  • Index - automatically generated, indexes a project-specific table

  • Description - usually the barcode

  • Expected Lane - automatically displays where the product is expected to divert

  • Confirmed - automatically displays the lane where the divert verified

  • LaneAlt1 - an optional alternate destination lane to be used in the event the destination is full

  • LaneAlt2 - a second optional alternate destination lane to be used in the event the destination and LaneAlt1 is full

  • LaneAlt3 - a third optional alternate destination lane to be used in the event the destination and LaneAlt1&2 are full

  • Box Size - automatically generated based on the induct eye's detection of the box

  • Fixed Dwell - dwell is the time to keep firing. A fixed dwell will keep firing for the time it takes to cover a fixed number of ticks. If this field is filled, it will override the Fixed Dwell field in the Outpoints table.

  • Percent Box Dwell - the number of ticks passing in front of the induct eye will represent the length of the box. The time to continue firing can be entered as a percent of the box. If this field is filled in, it will override the Percent Box Dwell field in the Outpoints table.

  • Armed - generated automatically in cooperation with the armed Friend field in the Outpoints menu
