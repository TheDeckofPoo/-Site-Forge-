System Status Log Menu

After pressing F10 then press a '1' , the System Status Log will be displayed. This keeps a chronological log of every error that occurs. It will display the date of the error, the time the error occurred, the description of the error and the duration of the error. Every time an error occurs it is put in this log.

This log is very useful for finding errors that occurred and have been reset without the proper person knowing an error has occurred. For example if an Emergency Stop is press and reset right away a supervisor or maintenance person may see the system is stopped and not know what caused the problem. If you go to this screen it will show what happened and when it happened.

On most systems Fortna has a housekeeping menu that automatically purges the error logs every week.

The following field columns comprise the menu.

  • Date: Shows the date that this particular instance of the error occurred.

  • Time: The time that the error occured.

  • Description: The description of the error that took place.
  • Duration: The total time that the error existed in the system.
