Edit Layer Sets

Parts belong to a numbered layer from zero up. Parts that belong to layer zero are a special case and are always displayed. A layer set chooses from each layer number whether parts belonging to that layer should be displayed. When FortnaPlus© paints the Main Screen, it displays any part that lies in the selected virtual coordinates that belongs to layer zero or whose layer is selected by the layer set.

Entries in the Layer Sets menu should be the specific names given to each view to be displayed on the screen. The order in which the names are entered does not matter here.
