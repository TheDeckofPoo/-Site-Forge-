Set World Views

When FortnaPlus© draws parts on the screen, FortnaPlus© uses virtual screen dimensions and maps them onto the actual screen dimension. The origin of the virtual screen is normally placed at the lower left-hand corner of the actual screen. The default maximum values are 64,000 for the x-axis and 48,000 for the y-axis.

The actual screen is 640 pixels horizontally and 480 pixels vertically.

FortnaPlus© supports multiple sets of x and y dimensions through a view table. A user can select a view by clicking on the View Window button. FortnaPlus© knows which section of the virtual screen should be shown on the screen.

Use Set World Views to add a view or edit the x and y coordinates of an existing view. The background color of a view can be selected with Fill Color.

Another way to create a view would be to use the slide bars and the zoomin or out buttons. Once the view seen is satisfactory, push the 'View ' button. Type in the name of a desired view. Click on the plus symbol in the lower right corner. The plus symbol associates the view with the name.

The button to the right is used to apply changes to an existing view.
