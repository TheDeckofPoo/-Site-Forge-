XferStatePop Menu

Below is a description of the transfer states in the Xfer State Pop menu:

XFER_IDLE:

WHEN
ProductINPUT is high
XferDownINPUT is high (or N/A)
XferClearINPUT is low (or N/A)
DestClearTM is done (or N/A)
and Go is 'Y'
SET State=XFER_RELEASE

XFER_RELEASE:

WHEN
Product INPUT is low
SET State=XFER_HOLD

OR WHEN

XferRaiseINPUT matches XferRaiseSENSE plus XferRaiseDELAY

SET State=XFER_RAISESET ReleaseOUTPUT to ReleaseACTION
SET DirectionOUPUT to DirectionACTION
SET RaiseOUTPUT to NOT RaiseACTION
SET DoneOUTPUT to NOT DoneACTION

XFER_HOLD:

WHEN
XferRaiseINPUT matches XferRaiseSENSE plus XferRaiseDELAY
SET State=XFER_RAISE
SET ReleaseOUTPUT to NOT ReleaseACTION
SET DirectionOUTPUT to DirectionACTION
SET RaiseOUTPUT to NOT RaiseACTION
SET DoneOUTPUT to NOT DoneACTION

XFER_RAISE

WHEN
XferDoneINPUT matches XferDoneSENSE plus XferDoneDELAY
SET State=XFER_DONE
SET ReleaseOUTPUT to NOT ReleaseACTION
SET DirectionOUTPUT to DirectionACTION
SET RaiseOUTPUT to RaiseACTION
SET DoneOUTPUT to NOT DoneACTION

XFER_DONE:

SET State=XFER_IDLE
SET Go='N'
SET ReleaseOUTPUT to NOT ReleaseACTION
SET DirectionOUTPUT to NOT DirectionACTION
SET RaiseOUTPUT to NOT RaiseACTION
SET DoneOUTPUT to DoneACTION
