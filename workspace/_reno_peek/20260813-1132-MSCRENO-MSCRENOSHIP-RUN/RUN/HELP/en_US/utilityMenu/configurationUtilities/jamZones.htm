Jamzones

The Jamzones menu configures zones or areas of conveyor to operate together as a unit. These configured units of system will stop together when an e-stop is activated. These 'jamzones' will also stop as a unit when a jam is detected within this zone. When this zone is selected from the Start/Stop menu, it will start.

The following fields are included in the Jamzones menu:

Zone Name - a description uniquely identifying this zone, up to 25 characters

Start Request Flag - a boolean field

Stop Request Flag - a boolean field

Latch Bit - this field brings up the Conveyor menu from which to select a bit that has been created and named after this zone enabling IO to display the status

Jammed Bit - this field brings up the Conveyor menu from which to select a bit that has been created and named after this zone enabling IO to display the status

Start Stop Timer - brings up the timer menu from which to select a timer to be the Start/Stop timer.

Zone Owner - brings up the Machine menu from which to select the machine controlling the zone IO

Enable Bit - this field brings up the Conveyor menu from which to select a bit that has been created and named after this zone

Start Button - brings up the Conveyor menu from which to select the start Push button on the panel.

Stop Button - brings up the Conveyor menu where 'ALWAYS ON ' is likely to be selected.
