Map Editor Help

Use the text fields to enter map coordinates directly.  Also you can use the arrow buttons for more precise map adjustment.  The middle button, located in the center of the arrow buttons, dictates the action of the arrows:

Middle button state Action of arrows
Change map position, don't change size
Increment map size *
Decrement map size *

* - hold Shift to keep map centered

To change the middle button state, click on it.
