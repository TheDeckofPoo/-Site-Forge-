Protocols

The Protocols screen lists the messaging protocols FortnaPlus© supports for data exchange with other systems or devices. The Protocols screen also shows the FortnaPlus© functions used to initialize handling of the protocol, maintain the protocol, build messages, and parse received messages for the protocol.

The protocol types are:

  • N/A - used in other tables as a filler. Its init, maintain, build and parse functions should all be set to page 0. This must always be the first entry in the protocols table.
  • HOST_SORTPLUS - used to communicate between FortnaPlus© controller systems.
  • HOST_STD - used to communicate with WMS systems using a sequence number and acknowledgement format.
  • HOST_RAW - used to communicate with devices such as scanners and scales. Messages for this protocol use no header information and require no acknowledgement.
  • HOST_ECHO - used to communicate with WMS systems that require echoing of the complete original message as an acknowledgement.
  • MOVE - used to communicate with MOVE systems.
