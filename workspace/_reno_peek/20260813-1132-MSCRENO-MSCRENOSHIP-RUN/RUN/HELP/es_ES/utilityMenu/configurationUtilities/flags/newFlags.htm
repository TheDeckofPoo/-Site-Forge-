New Flags


The New Flags Menu contains integer flags. Some of the flags in New Flags are shown below.

Click Here to see a screen shot of this menu.

Record #14 is used to turn on/off a carton index displayed through the shift print line in logs

Record #26 is used for the draw conveyor flag. A '1' in "flag value" causes graphical display
to disappear and text: "Conveyor is off" to display on the screen.

Record #29 contains current view index, CURR_VIEW, which is used internally

Record #30 contains flag, AUTO_LOGIN, enabling auto login. If it is set to 1, FortnaPlus© checks whether user guest already exists, if not, it creates user guest with password of guest and level=9900 and then performs auto login as a guest with no password dialogue.

Record #31 USE_HELPVIEWER, causes FortnaPlus© to use the Photon Help Viewer to view htm files when its value is set to 1.

Record #40 LOGS VERBOSE, turns on additional logging when its value is '1'

Record #41 LOGS VERY VERBOSE, turns on a second level of additional logging when its value is a '1'.

Record # 42 MASTER_IO_MACHINE. should reference the record in the Machine menu which holds the machine who should broadcast the IO states to all.

Record #43 I OWN ALL ERRORS is useful for testing or in a demo state. When set to a 1, this machine believes it owns all the Errors.

Record #44 AUTOSENDTIME, if set to 0, it will be set automatically when using flag #42.
