Jamzones

The Jamzones menu configures zones or areas of conveyor to operate together as a unit. These configured units of system will stop together when an e-stop is activated. These 'jamzones' will also stop as a unit when a jam is detected within this zone. When this zone is selected from the Start/Stop menu, it will start.
