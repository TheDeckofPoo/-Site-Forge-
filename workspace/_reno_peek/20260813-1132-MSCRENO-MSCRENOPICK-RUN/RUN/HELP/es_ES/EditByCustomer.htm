Edit By Customer

The Edit By Customer Menu allows the user to View, Edit, Add or Delete customer information by referencing the Customer Number.

Fields:

CustNo - The Customer Number is 6 digits. The digits entered will be padded with zeros on the left to fill 6 characters.

Retrieve - Click Retrieve to search for the matching customer number and display current selections. If the Customer Number is not currently in the database, the user is prompted to Add.

International - The International flag is either Y or N. If International, product is diverted to one of the lanes shown.

LaneA through Lane0 - These pull down menus are used to select the lanes to be used for this customer. LaneA represents the first lane choice, LaneB, the second lane selected, LaneC, the third lane and so on. A minimum of one lane must be selected in order to save this Customer Number.

Add - Enter a Customer Number. Select at least one lane and click Add to add this customer to the Customer database.

Save - Save must be selected in order for any new information or changes to be saved.

Delete - Choose Delete to remove the Customer Number from the Customer database. THERE IS NO UNDO!!

Escape or click the X in the upper right corner to exit this menu.
