System Timers

Timers can be accessed with the System Timers selection or by pressing F7. Timers are viewed one timer per screen, a type 2 menu. Use the right and left angle buttons to view the previous or next record. Page up and page down will also view previous or next timers.

Timers are used by FortnaPlus© to time system events. A software construct, they are used predominantly, but not exclusively, in full detection, jam detection and motor chains. Timers are added through timemenu. The ASCII file, timemenu.asc is found in the FORTNA directory.
