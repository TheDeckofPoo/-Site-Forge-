Trigger Sets

FortnaPlus© uses triggers like a PLC uses ladder logic. If there is something that needs to be controlled, and there is not already a pre-written module for it; it must be done in triggers.

Triggers can be very simple but they can also become very involved.

Writing triggers should not be attempted without additional training from Fortna. Do not leave any lines blank because the program scans the trigger menu from top to bottom and stops when it gets to the first blank line.
