Base Window Procedures

This is the list of internal FortnaPlus procedures that can be called via user defined hotkeys.  Use the KeyStrokes menu to associate a procedure with a hotkey.

Procedure Description
"Login" Open login window
"View On/Off" Turn View window on/off
"Zoom In" Zoom in
"Zoom out" Zoom out
"Repeat Action" Repeat last action
"Map" Open maps list
"Map Edit" Open map editor*
"Focus to menubar" Get focus to menubar
"Focus to toolbar" Get focus to toolbar
"Focus to conveyor" Get focus to conveyor screen
"Refresh Main" Redraw conveyor screen
"Conveyor Nodraw" Turn conveyor drawing on/off
"Display Errors" Open error screens list
"View PLC I/O" Open Input/Output screen
"Display Shift" Open Shifter screen
"Startstop" Open StartStop screen
"Exit Program" Exit FortnaPlus

*-the current view or conveyor screen must be map based, otherwise "Map Edit" will do nothing.
