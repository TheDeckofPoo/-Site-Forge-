Configure I/O

The Configure I/O table is used to link FortnaPlus© to the I/O racks in the electrical panel. The configure I/O screen contains the following fields:

Fields:

Bank - the bank number needed to reference the correct I/O rack.

Octal Word - the word address for the I/O from the electrical drawings

LoHi - byte in the word

In Out - zero for an input, one for an output

IO Type - brings up the IO Types menu displaying Digital, Analog, or Memory

Interface - brings up the IOCard menu displaying Pamux, Optomux, Memory, or AC5

Granularity - the monitoring granularity. A value of 0 or 1 causes monitoring to occur on every pass through the critical loop

Countdown - not used

Status -brings up the IO Status menu displaying whether the I/O connection was successful

Process - brings up the Process Type menu from which to select the controlling process
