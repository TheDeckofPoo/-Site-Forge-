Integer Flags

FortnaPlus© uses Integer Flags as permanent variables to store information and as signals between the various program processes. The first 100 flags are common to all FortnaPlus© installations. The flags above 100 are specific to a particular installation.

Some of the more important flags are:

  • pleasestart (flag 0) - please start is 1 when the system is running and 0 when the system is stopped.
  • TIMERGUI (flag 8) - controls the priority of the GUI process by setting the requested maximum time between time slices for the GUI process.
  • TIMERCRITICAL (flag 9) - controls the priority of the Controls process by setting the requested maximum time between time slices for the Controls process.
  • TIMERSORT (flag 10) - controls the priority of the Sort process by setting the requested maximum time between time slices for the SORT process.
  • JAM (flag 12) - set to 1 when a jam condition exists in the system.
  • PIXELS PER FEET (flag 14) - controls the scale of the main screen drawing (how many screen pixels are used to draw a foot of the conveyor system).
  • MYNODE (flag 53) - displays the node number of the PC.
  • FLAG PROTECT FORCE (flag 75) - when set to 1, restricts the other nodes on the system from using 'force' to control I/O devices controlled by this machine. When set to 0, allows other nodes the freedom to force or manually control the I/O devices controlled by this machine.
  • Project-specific flags, over 100, may include those specifying maximum number of times allowable for various utilities or functions, such as the following:
  • MAXCONSECNOREADS - used by scanstats
  • MAXCONSECNODATAS - used by scanstats
  • MAXRECIRCS - used by scanstats

Project-specific flags configuring use of lanes may also be included:

  • JACKPOTLANE - used by scanstats
