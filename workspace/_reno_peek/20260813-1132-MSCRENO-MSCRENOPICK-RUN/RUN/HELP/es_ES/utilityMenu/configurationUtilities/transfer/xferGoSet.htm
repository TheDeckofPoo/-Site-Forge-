XferGoSet Menu

The XferGoSet Menu contains up to 5 XferCfg records and the InitState for each. The fields of the menu are as follows:

Name - a description of the path of the product, for example the area where the product is coming from and where the product will go to, such as "RECIRC zone10", or "TX10 packing"

Xfer1 - brings up the XferCfg menu from which to select a path or partial path

InitState1 - brings up the XferStatePop menu where the
