XferTree Menu

The XferTree menu should hold one record for each full path that product may take. The following fields are included:

Name - a string uniquely describing the path, for example "xferSHIP straight"

Boss - brings up the XferBoss table from which to select the transfer this path is part of

GoBits - the string of ones and dashes indicating the destination(s) that would be accepted for this path by one or more 1's in a particular position. The word "ALL" entered here would indicate that all destinations are accepted here and would be considered a match.

NoGoBits - a string of ones and dashes indicating by positioning of a 1, the destinations which would not be accepted here.

MustBeIdle - brings up the XferCheckSet menu from which to select the path or set of paths that must be clear in order to allow product to transfer

BusyContinue - a boolean field. If 'Y' then if one XfetTree path is busy, the next path will be checked to see if it can accept this product.

XferSet - brings up the XferGoSet menu from which to select the path in this record

FullContinue - if this flag is 'Y' then even if one of the paths that must be idle is not clear, the logic will go on to check the next record in the XferTree.
