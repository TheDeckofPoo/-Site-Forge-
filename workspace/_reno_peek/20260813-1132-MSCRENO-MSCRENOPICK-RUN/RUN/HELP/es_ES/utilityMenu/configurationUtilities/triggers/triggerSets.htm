Trigger Sets

FortnaPlus© uses triggers like a PLC uses ladder logic. Triggers are used to control anything that does not have a pre-written module. Triggers are assigned to a FortnaPlus© process. Usually, the controls and GUI processes are used to evaluate triggers. As each process executes its critical path, the process evaluates the triggers that belong to it.

Triggers can be very simple but they can also become very involved. Writing triggers should not be attempted without additional training from Fortna. Do not leave any lines blank because the program scans the trigger menu from top to bottom and stops when it gets to the first blank line.

The Trigger Sets screen shows triggers that are currently false in red and shows triggers that are currently true in green.

Fields:

Trigger Set Name - a descriptive and unique name for the trigger that may be used in other menus

Trigger type - the trigger's type may be one of the following:

NONE - always false (this trigger is not used)
ONIO - true when the I/O is on (high)
OFFIO - true when the I/O is off (low)
ONTIMER - true when the timer is done
OFFTIMER - true when the timer is not done
ONFLAG - true if the integer or floating variable in a menu (table) matches the given value
OFFFLAG - true if the integer or floating point variable is greater than the variable in the menu
GREATERTHANFLAG - true if the given integer or floating point value is greater than the variable in the menu
LESSTHANFLAG - true if the given integer or floating point value is less than the variable in the menu
ONANIMATE - not used
OFFANIMATE - not used
DRAWTHESAME - forces one part to draw the same color on the Main screen as another
ONCOMBO - true when the given combination trigger is true
TRANSON IO - true when the given I/O transitions from off (low) to on (high)
TRANSOFF IO - true when the given I/O transitions from on (high) to off (low)
TRANSON TIMERDONE - true when a timer transitions from timing to done
TRANSOFF TIMERDONE - true when a timer transitions from done to timing
KEYSTROKE - not used
ENDBLOCK - marks the end of a block of triggers
ISTIMING - true when a timer is timing

loc - this field is automatically generated and is used to find the Triggerlocname value in the proper menu.

loc2 - this field is used to further define which variable to evaluate. This field is only used for ONFLAG, OFFLAG, GREATERTHANFLAG, and LESSTHANFLAG triggers. The loc2 value is the field (column) number of the variable in the menu. The fields are numbered from one.

loc3 - this field is used to further define which variable to evaluate. This field is only used for
ONFLAG, OFFLAG, GREATERTHANFLAG, and LESSTHANFLAG triggers. The loc3 value is the entry (row) number of the variable in the menu. The fields are numbered from zero

Trig val - this field contains the value for comparison with the variable for ONFLAG, OFFLAG, GREATERTHANFLAG, and LESSTHANFLAG triggers. This field is not used for any other types of triggers.

Resptype - the response type designates the action the process takes when the trigger is true. The response type may be one of the following values.


Type Description Action when Trigger is True Action when Trigger is False
NONE No response occurs. This response is used for unused triggers and the individual triggers that make up a combination trigger None None
RESP_DRAW This response draws a part on the screen in the designated colors. Triggers using this response must be referenced by the conveyor part(s) they are required to draw Draws the part in the Responcolor color Draws the part in the Respoffcolor color
RESP_FIRE Fires (raises high) the designated part. This response type cannot be used for any part listed in the motor chains Fires the part Unfires the part
RESP_UNFIRE Unfires (drops low) the designated part. This response type cannot be used for any part listed in the motor chains Unfires the part Fires the part
RESP_TIMERSTART Starts timing with the designated timer Starts the timer timing Resets the timer
RESP_TIMERRESET Starts timing with the designated timer Resets the timer Clears the timer reset
RESP_DATA Sets a variable to a value Sets the variable None
RESP_ANDBLOCK Used to create a block of triggers None None
RESP_SQL Executes an SQL command Executes the command None
RESP_DOPROC Executes a FortnaPlus procedure or function Executes the function or procedure None
RESP_ORBLOCK Used to create a block of triggers None None
RESP_ENABLE Used to enable (allow to run) a part listed in the motor chains Clears the part's 14th disable bit Sets the part's 14th disable bit
RESP_DISABLE Used to disable (stop from running) a part listed in the motor chains Sets the part's 14th disable bit if no Go Now bits are on for the part Clears the part's 14th disable bit
RESP_LATCH Used to turn on a part and leave it running Fires the part None
RESP_UNLATCH Used to turn off a part and leave it off Unfires the part None
RESP_GONOW Used to force a part listed in the motor chains to run Sets the part's 14th Go Now bit Clears the part's 14th Go Now bit
RESP_STOPGONOW Turns off the forcing of a part listed in the motor chains Clears the parts 14th Go Now bit Sets the part's 14th Go Now bit

Responcolor - used by RESP_DRAW to choose a color for drawing a part when the trigger is true

Respoffcolor - used by RESP_DRAW to choose a color for drawing a part when the trigger is false

Rloc - this field is automatically generated by FortnaPlus and is used to find the Resplocname value in the proper menu (table).

Rloc2 - this field is used by RESP_DATA to define which field (column) of the menu the variable is located in.

Rloc3 - this field is only used for RESP_DATA and RESP_SQL. For RESP_DATA this field defines which entry (row) of the menu the variable is located in. For RESP_SQL this field defines which SQL command is executed from the SQL Queries menu. SQL commands and variable entries are counted from zero.

Rvalue - this field is used for RESP_DATA triggers to designate the value to place in the variable.

Rproc - this field designates which FortnaPlus process is responsible for evaluating and executing this trigger.

State - this field records the state of the trigger from the last time it was evaluated.

Striggerlocname - a string name

Strig val - used in comparison triggers

SResplocname - This field and those that follow

SRloc - brings up the Conveyor menu

Srvalue - used in extended RESP_DATA functions

LogicRef - the second number in the logic help menu

Family - not used

PopUpMenu - which menu the trilogy (Loc, Loc2, Loc3) uses if a conditional situation exists

PopUpResp - tells the trigger where to access data if a response side condition exists

Popupsloc - conditional side of trilogy sets

Popupsrloc - response side of trilogy sets
