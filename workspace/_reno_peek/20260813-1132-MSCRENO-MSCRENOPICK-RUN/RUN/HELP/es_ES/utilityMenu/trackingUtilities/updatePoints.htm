Update Points

Each Sorter may have any number of update points configured in the Update Points Menu. Updates may be a scanner, scale, photoeye, sensors or whatever provides the necessary information.

The following columns are included in this menu:

Update Name - this string, if left blank will update automatically.

Sorter - a pull-down into the Sorter Configuration Menu.

Update Number - starts at zero for each sorter.

Location - the address of the update point, in ticks.

Name - a pull-down into the Conveyor Menu.

Window Size - the size of the window of data when looking for an update.

Description - the string entered here will be displayed in the graphical shifter display.
