1         Overview

The BASCO Shipping Sorter’s main function is to sort cartons to the proper shipping lanes. One over head omni-directional scanner will read a barcode and transmit it to the FortnaPlus control PC. FortnaPlus will parse the barcode and determine which of the 14 shipping lanes to divert the carton. FortnaPlus will also control diverts to the exception handling lane, “Jackpot” lane, used for no-read/bad reads. The run-out lane at the end is used if a shipping lane is full.

There are tables that contain a list of all the priorities and customer numbers that are used throughout the system. In the unlikely event of a large customer order or in the event that the system is expanded in the future, the tables are configured to allow multiple lanes per customer. The system will round robin between the multi-lane selections.

A listing of terms used within this document can be found in the Glossary section of this document. It’s advisable to read over those terms to become familiar with the terminology used throughout the document.

6.1      Edit Customer

The Edit Customer menu opens the Menu [ EditByCustomer ] panel, see Figure 8. From this panel a customer can be retrieved, added, modified, and deleted.

Each customer has a flag setting which determines if the customer is international or not. The flag should be set to “YES” for international customers and “NO” for non-international customers.

Each customer must have at least one lane assigned to them. They could potentially have every lane assigned to them. Each lane that is assigned to a customer determines a potential destination of a carton picked for that customer.

A customer number consists of a six digit number. It is zero filled, meaning a customer number will have zeros at the beginning if the actual customer number is not six digits long. For example, customer number 7019 is displayed as 007019. It is not necessary to type the additional zeros when retrieving, adding, or deleteing a customer.

Figure 8

6.1.1      Retrieve a Customer

Type a customer number in the CustNo text field and click the Retrieve button. If the customer exists, then the lanes assigned for the customer are displayed along with the international flag setting.

A result message is displayed in the blue text box at the bottom of the panel. Upon successful retrieval the message “Edit, Save, or Delete” is displayed. If the customer is not found then the result message displayed will read “Customer Not Found, Add”.

6.1.2      Add a Customer

Type the customer number you want to add in the CustNo text field if is not already displayed. Click the Add button. The result message displayed in the blue text box reads “Enter Information and Save”.

By default the International flag is set to “NO”. If you are adding an international customer click the down arrow on the drop down list box. A pop-up panel opens with two possible options. Double click the “YES” value. When the “YES” is double clicked the pop-up panel closes and the option you selected is displayed in the International text field.

Select a lane to assign to the customer. Start with the first unselected lane that reads “N/A”. This should be the LaneA designation for a new customer. Do not skip any lanes start with the first lane that has the “N/A” assigned to it starting from LaneA then LaneB then LaneC etc.

Click on the down arrow of the drop down list box of LaneA. This opens a pop-up panel titled Menu [Lane]. This pop-up lists all lanes within the shipping sorter, including the jackpot lane. The run-out line at the end of the conveyor is not a part of these lane assignments. Scroll through the list and double click the lane you want assigned to the customer. It does not matter if the lane is enabled or not. This is known by looking at the column titled “Enab” and the display reads either “YES” or “NO”. Disabled lanes are utilized by the sorter once the lane is enabled again. See sub-menu item 6.3 Lane details on enableing/disabling lanes.

When lane assignments are completed, click on the Save button. The customer data is saved and a result message is displayed in the blue text box that reads “Saved Info”. The current customer data is cleared and ready for the next customer to be added. Just click in the CustNo text field box to type in another customer to add.

6.1.3      Delete a Customer

Type the customer number you want to delete in the CustNo text field if is not already displayed. Click the Delete button. The customer is deleted. The result message displayed in the blue text box reads “Deleted, Exit or Continue with another Customer Number”.

The current customer data is cleared and ready for the next customer to be deleted. Just click in the CustNo text field box to type in another customer to delete.

6.2      Priority

The Priority menu opens the Menu [ Priority ] panel, see Figure 9. The priority panel is a grid like interface. The data contained in the grid is as follows:

  • Priority identification
  • Override flag setting
  • LaneA through LaneO assignments

 

Priorities are two digit numbers with a leading zero for single digit priorities. For example, priorities 0 – 9 are shown as 00, 01, 02, 03 etc.

 

The Override flag indicates if a priority is a high priority. Cartons with a high priority, Override flag set to “YES”, will be diverted to one of the lanes assigned to that priority. If a high priority is found, the Customer Number does not come into play in selecting a destination.

 

LaneA through LaneO assignments allow operators to assign up to 15 different lanes for that priority.

 

6.2.1      Setting the Override flag and making Lane assignments

To set a priority as a high priority, click on the down arrow on the Override field associated to the priority you wish to set as high. A pop-up panel opens with two choices, “YES” or “NO”. Double click the desired choice. The panel closes and the grid is modified, but NOT saved as of yet.

To set a destination lane for a priority, follow the row over to the right till you come to the first cell in the grid that has “N/A” assigned to it. Click the down arrow of that cell. A pop-up panel opens titled Menu [ Lane ]. This panel has all of the shipping lanes. Scroll through the list to find the desired lane, and double click that lane name. The panel closes and the grid is modified, but NOT saved as of yet.

You can remove a priorities lane assignment by selecting the lane name “N/A” from the pop-up panel that lists all of the lanes.

When you have finished making your modifications click the Save button. All the changes that you have made are saved, and the panel closes.

Figure 9

6.3      Lane

The Lane menu opens the Menu [ Lane ] panel, see Figure 10. From this panel a lane can be given a logical name. A lane can be enabled or disabled.

To give a lane a new name click on the cell to be changed. The data currently in the cell is highlighed. Type in the name you want to assign to the lane.

To enable/disable a lane look down the column titled “Enabled” and click on the down arrow of the lane you want to change. A pop-up panel opens with the possible choices of “YES”, which enables a lane, and “NO”, disables a lane. Double click the desired option. The pop-up panel closes and the grid is modified, but NOT saved as of yet.

When you have completed your modifications, click the Save button. The changes are saved and the panel closes.

6.4      Scan Info

The Scan Info menu opens the Menu [ ScanInfo ] panel, see Figure 11. This panel shows the following data elements:

  • Barcode – the barcode that was read by the scanner
  • CustNo – customer number parsed from the barcode
  • Priority – priority number parsed from the barcode
  • International flag – flag looked up from the customer number
  • Override flag – flag looked up from the priority number.
  • Divert assignment – lane assigned to divert the carton, labeled 0 – 15, with zero being no lane assigned.
  • Comment – short description of result of divert assignment
  • Status – the current status of the carton
    • 1 = triggers a  request to find the override priority lanes
    • 2 = override priority lanes have been found
    • 3 = triggers a request to find the international customer lanes
    • 4 = international customer lanes have been found
    • 5 = triggers a request to find the least recently used and available lane
    • 6 = Not Used
    • 7 = destination lane has been assigned
  • LaneArray – an array of data bits to represent each lane. Each value in the array indicates what each lanes association as a potential divert to the carton that was scanned. The possible data values in the array are listed below:
    • First Data bit position:
      • 1 = using priority to select a lane (look for ‘P’s in array for potential destinations
      • 2 = using customer to select a lane (look for ‘C’s in the array for potential destinations
      • 3 = using priority and customer to select a lane (look for ‘B’s in the array for potential destinations
    • Data bit positions 2 – 15:
      • 0 = not selected (this is typically the exception handling/Jackpot lane)
      • C = customer only matches for lane selection
      • P = priority only matches for lane selection
      • B = both customer and priority match for lane selection

 

This panel is used for getting additional information as to why a carton diverted to a specific lane.

Figure 11

6.5      Edit Jackpot Lane

The “Jackpot” lane is the exception handling lane. It handles no reads/bad reads from the scanner. This lane is typically the first lane after the scanner. It’s typically referred to as “the Jackpot lane”. For FortnaPlus to properly divert cartons for no read/bad reads, it must identify which lane is considered “the Jackpot lane”. This lane must be given a logical name to identify it. By default the lane is called “Jackpot” within FortnaPlus.

To set “the Jackpot lane”, select the Edit Jackpot Lane menu. A panel opens titled Menu [ ProjectFlags ], see Figure 12. The row with the Name called “Exception Lane Name” holds the logical name under the column called StrFlag. The name used is “JACKPOT”. Click the Save button. The panel closes.

The logical name used for the “Exception Lane Name” needs to match one of the Lane names in the Lane table, see Figure 13. You will see the first lane has the Name of “JACKPOT”, just as it is appears in the StrFlag column for the row that has the Name of “Exception Lane Name”.

IT IS VERY IMPORTANT THAT BOTH OF THESE VALUES ARE THE SAME.

If they do not match then the Exception handling lane will not function properly.

9         Appendix C

Sortation Criteria

The over-head omni scanner on conveyor P-400 will read the routing priority and customer # from the label and transmit this to the FortnaPlus control PC. The FortnaPlus control PC will locate the appropriate lane from the lane assignment configuration tables and divert the carton off the pusher sorter and onto the gravity skate wheel after-sort lane where it will be palletized.       

There are two initial checks on the barcode data to determine the correct divert lane. The first check is to see if the shipping priority is an override type priority. As of the writing of this document, BASCO has the following as override type priorities: 01 DP/EM (emergency), 02 No Priority, 06 Low Wt-Internal Usg, and 07 WEB UPS Next Day. If ANY carton has one of these override type priorities FortnaPlus will divert these cartons to either lane 2 (G502) or lane 3 (G504) regardless of the customer number.  These override lane designations are assigned and configurable by BASCO associates within FortnaPlus, see 6.2 Priority.

If the shipping priority is not an override type then the next check is based on the customer number. There are customers that are international and must be handled by shipping lanes configured for international usage. The customer lookup table will have a flag set for all international customers. When an international customer is scanned within the barcode, it will be diverted to either lane 4 (G506) or lane 5 (G508). These international lane designations are assigned and configurable by BASCO associates within FortnaPlus, see 6.1 Edit Customer.

If the barcode does not contain an override shipping priority or an international customer number, then the default sortation rule is used. The default rule states that for a carton to be diverted, its shipping priority AND customer number must match what is assigned for a shipping lane.

If a customer has multiple orders routed through the sorter, then the priority designation of the bar code will be the determining factor as to which lane the order is diverted.

It is the responsibility of BASCO associates to enter the shipment priority and customer number into FortnaPlus prior to the package being scanned by the overhead scanner. If the barcode does not match both the shipment priority and the customer number, then the carton will diverted to the exception handling, “Jackpot”, lane (G500).

All lane full conditions result in the carton continuing to the run-out line at the end of the conveyor.

10    Glossary

  • GUI – Graphical User Interface, (pronounced “goo-ee”) the interactive program the Operator will use to complete their daily tasks.
  • operator – Employee that will use and operate the GUI.
  • desktop – The working area of the screen where program icons, such as the FortnaPlus “fp” icon can be selected to start an application.
  • drop down list box - This is a data selection object where only one entry from the list box can be used. To select an entry from a DDLB the operator must use the mouse and left click on the “Down Arrow” to the right of the text box. This will drop down a list of possible selections. The operator should then click on the entry desired. If there are more entries that can be viewed in the drop down list, then a Vertical Scroll Bar will appear on the right of the list box.
  • panel – A panel is a window-like display that is opened when a menu item is selected. A panel displays information or allows data entry for the operator.
  • closing a panel – To close a panel click on the small “X” in the upper right-hand corner of the panel you wish to close. If you click the outer most “X”, it will close the entire program. You can also close most panels by pressing the ‘Esc’ key on the keyboard.
  • grid and cell – A grid is a panel that displays data in columns and rows. The intersection of a column and a row is called a cell. Each cell holds one piece of data. When data modifications are made the data is changed in one cell at a time.
