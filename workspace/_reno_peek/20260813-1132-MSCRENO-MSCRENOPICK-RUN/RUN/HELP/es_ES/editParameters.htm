Edit Parameters Menu

Fortnaplus© keeps records in the Parameters menu to allow various functions to replace text with the data pointed to by the Parameter record. Basically, anywhere a string data type is used in fortnaplus©, the user may type %xxxxxx% in any part of the string. Fortnaplus© looks for an entry in the Parameters menu whose "Parameter Name" matches the string between the percent signs ("xxxx"). If a match is found, the "xxxx" portion of the string data is replace by the data pointed to by the Parameters record. The Parameter menu contains the basic fortnaplus© "Trilogy" columns, menu,column,and record. This points to data in the popupmenu, at the column, and record. If the Parameters column "Use Record" is a "Y", then the data will be from the currently focused record of the target menu instead of the popped up record. Common uses are PartNames in Conveyor.asc or sql query statements.
