System Status Analysis

To get to this screen press F10 and the number '2'. This screen will display the accumulated errors that have occurred since the last time the errors were purged. It will display the description of the errors, the total duration of the errors since the last purge and the total number of times the errors have occurred since the last purge.

This screen is very useful for finding problems that may be occurring on a regular basis that individually do not seem to be a problem but when added up over the course of an entire day may be costing you down time.

The following field columns comprise the menu.

  • Description: The description of the error that took place.
  • Duration: The total time that the error existed in the system.
  • Count: Shows the number of times that the error occured on the system.
