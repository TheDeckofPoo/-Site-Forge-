Divert Points / Sorter Outpoints

This menu is used to configure the divert points on a sorter. The Outpoints Table is displayed. The Outpoints Table controls the points where items are diverted, monitors whether the lanes are full, and verifies that diverts have actually occurred.

Outpoint Name - this string will automatically fill in if left blank.

Sorter - a pull-down into the Sorter Configuration table.

Outpoint Number - ranging from 0 through the number of outpoints on this sorter record.

Outpoint Location - the tic location of the outpoint.

Outpoint I/O Name - a pull-down into the Conveyor file.

Verify Location - the location of the verify photo eye.

Verify I/O Name - the name of the verify photo eye.

Fullclr Timer Name - a pull-down into Timers. The clear timer is used by the full lane photo eye.

Trigger I/O Name - the name of the photo eye prior to the divert.

LoLane - the lowest lane that will be accepted at this divert.

HiLane - the highest lane that will be accepted at this divert.

Retent - holds the last state.

Latch - only fire the output, do not unfire the output.

LoAltLane - the lowest lane that will be accepted to this divert.

HiAltLane - the highest lane that will be accepted at this divert.

LoAlt1Lane - first alternative lowest lane accepted at this divert.

HiAlt1Lane - first alternative highest lane accepted at this divert.

LoAlt2Lane - second alternative lowest lane accepted at this divert.

HiAlt2Lane - second alternative highest lane accepted at this divert.

Set Fixed Dwell - the number of ticks to keep firing.

Percent Fixed Dwell - this integer represents a percent of the carton added to the Set Fixed Dwell value.

Percent Box Dwell - info displayed here is automatically copied from the data table.

Set Fixed Delay - if set in the data table, the value is automatically shown here.

Percent Box Delay - if there is a BoxDelay set in the data table, it will be copied here and used.

Dwell - if there is a dwell set in the data table, it will be copied here and used.

BoxDelay - if there is a BoxDelay set in the data table, it will be copied here and used.

Don't Set Expect - a boolean field, set to an N if &qout;set expected" is not needed.

ArmFriend - used to have multiple outpoints fire same box, index in data to other outgoing.

UseArmed - set to a Y on the second output to fire.

RatePop - a pull-down into the Rate table. Used to limit throughput to any given lane.

Enable IO - optional I/O to use, which, if on, would be treated as a full.

Number of Diverts - holds the data of the number of boxes that have been diverted

FireBackDSV - the name of the Double Solenoid Valve that is fired after the divert.

FireBackDwell - the duration in ticks to fire the DSV in the fire-back cycle.

FireBackCount - keeps track of how many ticks have passed in the fire-back cycle.
