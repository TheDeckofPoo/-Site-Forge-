Message Map

The message map controls the flow of out-bound messages, and FortnaPlus© recognition of in-bound messages.

Fields:

Message Name - the name of the message for reference in code

Machine Name - the name of the machine as it is configured in the machine table

Recv Msg Type -incoming messages are scanned for this pattern at the beginning of the message or receive ALL

Send Msg Type - outgoing messages may use this field to start the message

Ack Msg Type -incoming messages are scanned for this pattern at the beginning of the acknowledgement

Menu Name - name of the menu the from which the data will come

Menu Index - automatically fills in reference to the menu

Low Cursor - the lowest column in the menu to store data

High Cursor - highest column in the menu to store data

Stat Cursor - column in the menu used to contain the message status

Last Record - holds the index to the last record filled in by a message

Low Head - the number of the field that the data will start to be inserted into for message headers

High Head - the number of the field that the end of the data will be inserted into for message headers

Key Cursor - the number of the field that will hold the database key

Id - the field which the Ignore Dupes feature looks at for duplicates

Last Id - the field where the Ignore Dupes feature stores the last value from the Id field

Record - the number of the record to use for this message (used if the menu holds more than one message)

Delimiter - brings up the Ascii menu to select a delimiter if used

Field Length - column which specifies the length fo the binary large data object

AckLen - length of acknowledgement header

CheckFile - logical yes if msgmap entry specifies a filename for ftp, nfs, or samba
