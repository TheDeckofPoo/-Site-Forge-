Horns

The Horns menu allows for configuration of the warning horns or beacons. Here you can set up one or more horns and/or beacons to activate within a configurable time framework.

Fields:

name - the string uniquely describing the horn

hornio - brings up the Conveyor menu, from which the I/O of the horn can be selected

newseq - brings up the timer menu, from which a timer to act as the sequence timer can be selected

sound - brings up the timer menu, from which the timer to act as the sound timer can be selected

ontime - brings up the timer menu, from which the timer timing how long the horn sounds can be selected

offtime - brings up the timer menu, from which the timer can be selected

go - value filled in by program code whenever a horn is to be sounded

isdone - displays a '1' when the horn is done, '0' when not
