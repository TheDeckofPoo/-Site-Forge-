Saving Data

By selecting SaveData, you are saving the current setting of all the FortnaPlus© tables. This includes all the custom configurations as well as the standard menu selections.

Every time the FortnaPlus© program is closed with Ctrl-F10, all of the settings are automatically saved. If while you are running, you, or Fortna personnel, make configuration changes of any kind, it is advised to select SaveData in order to be sure to retain the new values.

If you did not SaveData, you are vulnerable to an abnormal system shut down.

If, for example, you adjusted the firing point of a few diverts to cause some new cartons to divert more accurately and then lightning causes a power outage, your system may shut down abnormally if you did not use the Ctrl-F10 keys in time. You would lose any changes made in configuration since the last time the system closed normally. If you remember to Save Data after all changes, you will be assured not to lose them.

The screen will return to the main menu when finished saving data.
