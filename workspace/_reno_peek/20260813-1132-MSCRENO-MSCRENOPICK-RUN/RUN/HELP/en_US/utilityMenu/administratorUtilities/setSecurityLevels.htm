Set Security Levels

Selecting Set Security Levels will display the Security Menu, which lists all the functions in FortnaPlus©. When FortnaPlus© opens a menu or screen, it checks whether the user-ID's security level is less than or equal to the level listed for the screen or menu. If this check passes, the user can open the screen or menu. Otherwise, FortnaPlus© ignores the screen or menu. The Security Menu has the following fields:

Fields:

Procedure Name - The system automatically lists all available FortnaPlus© procedures here.

Security Level - Entries of 1-9999 are valid. A value greater than or equal to the current user's security privilege level will allow the procedure to execute.
