Current System Status Menu

Number 0 displays the current errors on the system. It will display the error description, the suggested action to be taken, the time the error occurred and the duration of the error. The error will only be displayed on this screen while the error is current. As soon as the condition that set the error is reset, the error will no longer appear on this screen.

The following four field columns comprise the menu.

  • Description: Shows a description of the error. This can either be a communication problem with other pc's or a full eye or jam condition.

  • Suggestion: Displays a suggestion to remedy the described condition. Not all errors will have a suggestion.

  • Time: The time that the error occured.
  • Duration: The total time that the error existed in the system.
